# ffmpeg-ios-lgpl

Reproducible, **LGPL-only** FFmpeg for iOS (device + simulator) built on GitHub Actions (`macos-26`), shipped as one dynamic `FFmpegLGPL.xcframework`
(VideoToolbox, libvpx, libopus, libvorbis, libmp3lame, libwebp, dav1d; no GPL, no x264/x265/fdk-aac). Used by Ecom Swift LLC video apps.

Run **Actions > Build FFmpeg LGPL xcframework > Run workflow** with a tag (for example `v7.1.1-1`) to publish a release with checksums.
